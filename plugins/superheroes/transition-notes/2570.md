### Before you upgrade

- **After switching.** **A caller that passes `--commit` to `cloud_plugin_pin.py write` or `remove` is now refused `commit-not-used` and nothing changes; `status` reads `--commit` as before.** See [Cloud plugin pin: write and remove refuse a commit they would not use](#cloud-plugin-pin-write-and-remove-refuse-a-commit-they-would-not-use).

### Cloud plugin pin: write and remove refuse a commit they would not use

- **The change.** `cloud_plugin_pin.py write` and `remove` given `--commit` answer `{"action": "refused", "reason": "commit-not-used", "detail": …, "changed": []}` and change nothing. Before, they ignored it, so `write --commit <sha>` pinned the release installed on this machine, not the commit asked for.
- Replacement. Drop `--commit` from `write` and `remove`; pass it to `status` only.
