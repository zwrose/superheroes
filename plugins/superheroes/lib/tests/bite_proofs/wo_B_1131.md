`_cmd_record_result_locked` (`plugins/superheroes/lib/round_driver.py:6304`).

`sweep-supersede-unsupported` rather than falling through to a sweep that ingests nothing and

## BP-B2 — explicit `--occurrence` in the emitted recovery command (`test_record_result_sweep_supersede_recovery_is_occurrence_safe`)

**Guarded element:** `_record_result_recovery_cmd` in `plugins/superheroes/lib/round_driver.py` —
that it emits the **raw seat key** plus an explicit `--occurrence <n>`.

**Axis:** the emitted recovery command addresses the intended roster slot. Every `seat-missing/1`
envelope shares one CAS token (`MISSING_CAS_TOKEN`), so a command that emits the `<seat>#<n>`
display label and drops `--occurrence` would pass CAS against occurrence **0** and supersede the
wrong durable record.

**Neutralization** (targeted, reversible):

```diff
-            "--occurrence %d --supersede --expect-sha256 %s"
-            % (shlex.quote(driver_path), shlex.quote(session_dir), shlex.quote(seat_key),
-               occurrence, shlex.quote(token)))
+            "--supersede --expect-sha256 %s"
+            % (shlex.quote(driver_path), shlex.quote(session_dir),
+               shlex.quote(_slot_label(seat_key, occurrence)),
+               shlex.quote(token)))
```
