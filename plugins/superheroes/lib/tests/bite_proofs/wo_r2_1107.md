# Ordered round R2 (#1107) bite-proofs — the four authorized clusters

Every proof below was **re-run by the orchestrator**, not inherited from an implementer report.
Mutations were applied as targeted revertible edits through the host's edit action (never a
whole-file rewrite, never a git discard), each reverted by its inverse edit, with
`git status --porcelain` confirmed **empty** afterwards. All commands ran under
`-B -X pycache_prefix=/private/tmp/superheroes-pyc` so Apple Python's out-of-tree bytecode cache
could not serve stale objects across same-second edits.

## BP-A1 — member validation at the open-set boundary

**Guarded element:** `_open_audit_ids_from_not_discharged`'s per-member `isinstance(member, str)`
check — the validated boundary that makes a malformed `notDischarged` member reach `unresolvable`
instead of raising.

**Neutralization:** removed the member loop, leaving only the container `isinstance(..., list)`
check — i.e. restored `set(not_discharged)` over unvalidated members.

**Red run:**
```
E       TypeError: unhashable type: 'dict'
plugins/superheroes/lib/round_driver.py:3084: TypeError
2 failed, 2 passed in 0.40s
```

This reproduces the original defect exactly: a `TypeError` raised **before** terminal routing, so
the tri-state park is bypassed.

**Honest limitation, recorded rather than smoothed over:** of the four parametrized cases, only the
two using `{}` go red under this mutation. `0` and `None` are hashable, so with validation removed
they still resolve and still reach a park by another route. The parametrization is therefore only
**partly** load-bearing against this specific mutation — the `{}` cases carry it. Noted so a reader
does not over-read "4 cases" as "4 independent detectors".

**Green run after revert:** `11 passed in 3.37s` (whole file).

actually **calls** `_settle_delta_converged`.

carries it). The **old** assertion `assert "_settle_delta_converged" in route_src` would therefore
still have passed; the repo's own prior record captured exactly that as `6 passed in 0.30s`.

so the earlier 80 s + 46 s scan cost is not reintroduced.
