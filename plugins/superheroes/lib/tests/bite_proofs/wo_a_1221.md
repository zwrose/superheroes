## G1 — the `GATE_GUIDANCE` wiring in the `P_FIXER` order-placeholder branch

`"GATE_GUIDANCE": _gate_guidance_block(fix_batch)`. Axis: the emitted fixer order actually carries
the batch's guidance rather than a constant.

**Neutralization:** replaced the derivation call with the literal no-guidance string — the exact
shape of the pre-change defect, where the order carried no guidance at all:
```
-            "GATE_GUIDANCE": _gate_guidance_block(fix_batch),
+            "GATE_GUIDANCE": "No owner-gate guidance is attached to this batch.",
```

The literal is spelled out rather than referencing `_GATE_GUIDANCE_NO_GUIDANCE`, so the probe pins
the real channel and not a symbol both sides read.

## G2 — `_escape_guidance_placeholder_syntax`

**Guarded element:** `round_driver.py` `_escape_guidance_placeholder_syntax`. Axis: owner guidance
can neither inject an order placeholder nor wedge the render. `render_order` substitutes by
iterating a **set** of template placeholders with sequential `str.replace`, then refuses on any
`{{…}}` left behind — so unescaped owner text is both an injection vector and a denial-of-render.

**Neutralization:** returned the text unescaped:
```
-    return text.replace("{{", "{ {")
+    return text
```

## G6 — the fold-stamped finding id read in `_gate_guidance_block`

`FIX_BATCH_GUIDANCE_ID_KEY` off the row instead of re-deriving ids over the fix batch. Axis: the id

guidance to. This is the defect the orchestrator's own verification caught on WO-A's head:
`_judgment_row_ids` is position-dependent, so a mechanical blocker sharing a location with the guided
finding shifted the guided row into the `#1` occurrence slot and the two ids disagreed.

```
-    guided = []
-    for row in batch:
+    row_ids = _judgment_row_ids(batch)
```

## Note on what these proofs do and do not establish

Each proof shows the named detector goes **red** when the thing it guards is neutralized, with the
detector itself unedited, and **green** again on restore. They do not establish anything about the
fixer agent's *behaviour* on receiving the guidance — that far side is a model reading prose, and no
live fixer smoke was run. See the PR's disclosed degradations.
