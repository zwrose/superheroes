## E8 — `configure()` idempotent early return

**Guarded element:** `configure()` early return when `self.configured` — axis: a second
`pytest_configure` with an empty xdist worker payload must not drain live watched state.

**Neutralization:** `if self.configured:\n            return False` →
`if False and self.configured:\n            return False`.

**Red run:**
```
FAILED ...::test_live_guard_survives_empty_worker_reconfigure
E       assert True is False
1 failed in 0.08s
```

**Restore:** inverse edit restoring the `if self.configured:` early return.

**Green run:**
```
5 passed in 0.09s    # E8–E12 bite tests, including test_bite_configure_idempotent_early_return
```
