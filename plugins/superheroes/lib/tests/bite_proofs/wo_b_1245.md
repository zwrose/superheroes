## Stated coverage limits

- **The census's shape coverage is bounded and does NOT terminate by construction — this is the
  build's parked seam, not a closed list.** The matcher is a hand-rolled per-AST-shape pattern set,
  so it detects exactly the shapes someone enumerated and silently passes every shape nobody did.
  Three consecutive review rounds each surfaced a *different* previously-unenumerated shape, which is
  the evidence that the enumeration is open-ended. The build's **third-rework tripwire** fired on this
  file (workhorse charter §7 / `rubric/review-discipline.md` § The third-rework tripwire), so the
  remaining shapes are **handed up as a design signal rather than patched one node at a time**. The
  shapes confirmed to escape as of `077c9748`, each demonstrated by an independent review seat with a
  read-only AST probe:
  - **binding targets** — chained (`other = fam = model_family(...)`, blocked by
    `len(stmt.targets) == 1`), tuple (`fam, other = model_family(...), x`), and attribute
    (`self.fam = model_family(...)`; `_same_subject` compares `ast.Name` ids only, so a dotted
    subject is unreachable by every pattern arm);
  - **statement kinds `_linear_stmts` never traverses** — `Try.finalbody`, `AsyncFor` and `AsyncWith`
    (not subclasses of `For`/`With`), and `Match` bodies;
  - **nested function scopes** — `_linear_stmts` skips nested `FunctionDef`/`AsyncFunctionDef`, and
    each nested scope gets a fresh `bound` map, so a nested guard over an outer binding escapes;
  - **branch flattening** — an `If`'s body and `orelse` are concatenated into one linear binding
    state, so a rebinding on the mutually exclusive arm can erase a reachable binding;
  - **walrus subjects** — `_bare_truthiness_test` / `_same_subject` never unwrap `ast.NamedExpr`, so
    `if fam := model_family(v, m):` is enumerated as a call site but yields no violation.

  **This list is illustrative of the class, not exhaustive** — that is exactly the point being handed
  up. **No shipped module uses any of these shapes today**, so none is a live miss; the census still
  bites the two shapes that matter in practice (in-place guard, plain assign-then-guard), both
  bite-proved above. What the census is *not* is a complete fall-open guard, and it should not be read
  as one.

- **`test_family_for_allowlist_justifications_are_non_empty`** carries **no** bite-proof.
  Neutralizing it means writing an empty justification into the allowlist, which is an edit to the
  detector's own data rather than to a guarded surface — the proof would be circular. Disclosed as
  unproven rather than claimed.
- **`test_family_for_none_tolerance_allowlist_matches_live_sites`** is exercised indirectly: BP4's
  neutralization adds a consumer module and BP1/BP2 exercise the shared pattern matcher, but no
  dedicated red→green proof was recorded for the per-function allowlist drift assertion itself.
  Disclosed as unproven.
- **The P1–P6 pattern arms are unit-exercised, not bite-proved.** The review loop's round-1 fix added
  `test_pattern_matcher_arms` (a parametrized synthetic-source exercise, one row per arm) plus a
  clean-shape negative row; that kills the mutants the P4/P5 arms previously survived. BP1 and BP2
  above bite-prove P1 and P2 against the real shipped surface; P3–P6 rest on the synthetic unit rows.
- **Module enumerations are keyed by `os.path.basename`.** Two same-named shipped modules in
  different trees would collapse into one key. No such collision exists today; disclosed, not fixed.
- **The census is AST-over-Python only.** The shell `python3 -c` consumer in
  `plugins/superheroes/skills/review-code/reference/setup.md` is structurally invisible to it; the
  failure message names that file so a reader is not left believing it is covered. Stated limitation,
  not a covered case.
