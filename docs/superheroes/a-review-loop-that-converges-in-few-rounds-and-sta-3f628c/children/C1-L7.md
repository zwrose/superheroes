What: Only the independent verifier grades a finding, and only it closes one as wrong. Today a per-finding verification pass gives CONFIRMED, PLAUSIBLE or REFUTED verdicts with quoted evidence (`plugins/superheroes/skills/review-code/reference/verification-pass.md`, `rubric/orders/dispatch-verifiers.md`), but other routes can also close a finding, such as the author-justification post-filter. This layer:
- makes the verifier the only actor that closes a finding as wrong (`shown-wrong`): the build session, the other reviewers and every filter may keep, merge or carry a finding, never close it as wrong (FR-2, R6);
- has the verifier grade each finding on its own as confirmed, plausible or wrong with its reason, using the break-it output C1-L6 saved where there is one, and writes the grade and reason to the record (FR-14);
- closes a finding as wrong, sending it to no fix, when its break-it test passes on the unfixed code down the finding's own path (FR-15);
- when the verifier judges that a passing test never reached the finding's path, gives a fresh run of the test reviewer the finding, the first test, its output and the verifier's note, and it writes one more test, which the build session runs as C1-L6 runs the first (FR-16);
- when that second test also passes, has the verifier decide on the evidence it has, closing the finding as wrong or keeping it as a judgment call without a test; no third test (FR-17);
- adds the glossary entry for the verifier (R15).

DoD:
- Tests: no path other than the verifier's grade writes `shown-wrong` to a finding; the build session's and the post-filters' attempts are refused or leave the finding open (FR-2). A record written from fixtures closes nothing as wrong without a verifier grade.
- Tests: every graded finding carries confirmed, plausible or wrong and a reason in the record (FR-14).
- Tests: a break-it test passing on the unfixed code down the finding's path closes the finding as wrong and it reaches no fix (FR-15); one judged to have missed the path brings a fresh test-reviewer run that receives the finding, the first test, its output and the verifier's note, and writes one more test (FR-16); a second passing test ends with the verifier closing the finding or keeping it as a judgment call, and no third test is requested (FR-17).
- `verification-pass.md` and the verifier's order state the grade, the missed-path step and the one-more-test limit.
