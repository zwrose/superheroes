What: The plugin's one visual theme and the review template's shell, the seam C8 and C4 build on. Layer 1, the theme: Comic panel, shipped once as one stylesheet with its fonts declared (R19), for every sheet, every review page and the frame and labels of every board, while a board draws the product itself in the project's design system. Each colour has one job: paper `#FFF8E7` for the ground; ink `#111111` for text, outlines, shadows and arrows; hero blue `#1B4FD8` for the owner's moments and the main action; alarm red `#D7263D` for warnings; highlight yellow `#FFC93C` for app bars, what's new and standing rulings; reviewer green `#0F7A4F` on `#E3F4EA` for independent reviewers only. Headings in Bricolage Grotesque 800, body text in Atkinson Hyperlegible 400 and 700, labels in the body font in tracked capitals, tags and Canon entries in IBM Plex Mono. Parts: 3px ink outlines (2px on small parts); offset shadows, never blurred (6px on cards, 4px on small boxes, 3px on buttons); corners of 6 to 14px; no gradients and no emoji. All text meets 4.5 to 1 contrast, white text sits only on blue, red or ink, every control is at least 44px tall, and colours that must be told apart also differ in lightness. A specimen page shows all of it. Layer 2, the template shell: one review template, a light web app that works on a phone first and on a desktop too, which loads a sheet's one data file (R17) and renders it in the theme; this layer lands the data file's schema with its field names, and a usage doc saying how a session publishes a sheet (the template plus its data file, private to the owner). The cards' full anatomy, the sheets, images and answers are C8's.

**Register entries this child consumes (quoted verbatim from docs/superheroes/spec-alignment-landing-2026-10-05/register.md; the register-quote check runs at filing, intake, and the package read):**

> **R17 — The sheet data file.** A sheet is the plugin's review template published together with one data file that holds the sheet's cards; no session edits the template's code to make a sheet, and the data file is also the sheet's saved source. The data file names the sheet's kind (a remainder sheet, a final sheet, or a plain sheet for any other review) and its title; for a remainder sheet, the facts behind "why only these" (rounds run, fixes made, any finding the review didn't settle); for a final sheet, how the spec got there (review rounds, fixes, the vet), the folded declined findings, and the approval card's facts (whether there is an approved board and whether it is saved with the spec). Each card carries a stable id, the kind of call, whether it carries the warning badge, the question, its context (what is true now, why it needs the owner, the exact text), its images, its options each with a plain consequence, and a one-line recommendation with its reason. The data file's field names are decide-by: C7, which lands the schema with the template.

> **R19 — The theme ships once.** The Comic panel theme ships as one stylesheet, with its fonts declared, at a path C7 names; the review template and every board's frame and labels load it, nothing else restates a theme colour, font or part rule, and a board draws the product itself in the project's design system, never in the theme. The path is decide-by: C7.
