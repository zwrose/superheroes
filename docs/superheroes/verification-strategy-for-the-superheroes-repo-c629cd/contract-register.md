# Contract register — verification-strategy package (spec #1105)

**What this is.** The package's binding sentences — the contracts more than one child builds
against — each numbered, each naming its producer and consuming children, each either **decided
now** or marked **decide-by** naming the child that owns the decision. Register-consuming child
issues quote their entries verbatim (the register-check gates filing). Authored by the advisor
(2026-08-28) under walk-11 ruling 5-a; the coverage map beside this file allocates criteria, this
file binds contracts.
