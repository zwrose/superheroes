# Contract register — verification-strategy package (spec #1105)

**What this is.** The package's binding sentences — the contracts more than one child builds
against — each numbered, each naming its producer and consuming children, each **decided now**
(round 1 of the package read eliminated every open decide-by: two were timing hazards — the
decider landed after its consumers — and one named a child that could not decide it; see
[package-read.md](package-read.md)). Register-consuming child issues quote their entries verbatim
(the register-check gates filing). Authored by the advisor (2026-08-28) under walk-11 ruling 5-a;
revised after package-read round 1. The coverage map allocates criteria; this file binds contracts.
