Each entry: the ruling, whether it's standing (applies to all later work) or for this piece, your exact words where there are any, and a pointer to where it was said: the session and the time. No transcript line numbers; transcripts live on one machine and expire.

What Canon holds

Decisions from every session, committed the moment they're made. Go-words (merge, launch) stay where you give them.

Principles: standing rulings, often born from a category 7 case.

Ceded calls: "you decide these from now on." Configure item 13 points here.

Who reads it

Discovery reads it first, so nothing you've ruled is asked twice. The source check traces tags back to it. The advisor's vet checks a spec against it, across every piece.
